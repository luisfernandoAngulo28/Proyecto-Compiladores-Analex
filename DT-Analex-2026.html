Comentarios que se ignoran: // … EOLN (termina en el salto de línea) · // … EOF (termina al acabar la cinta) · // … // (termina en otro //) · /* … */ (multilínea). Un /* … sin cerrar o un literal sin cerrar devuelven <ERROR,_>. Al cerrar un comentario se vuelve a q0 y se busca el siguiente token.

q13 sirve para distinguir una / suelta dentro del comentario de la pareja // que lo cierra.
